# still, the Life goes on — Image Gallery

A responsive, cinematic photo gallery inspired by the muted blue-grey, quiet winter-light, and reflective mood of BTS's BE era and the theme of life continuing through ordinary days. This is an original fan-inspired aesthetic, not an official BTS website.

## Files
- `index.html` — gallery structure and nine photo cards
- `style.css` — blue-grey styling, responsive CSS Grid, hover effects, lightbox design
- `script.js` — category filters and keyboard-accessible photo lightbox

## Features
- 3-column desktop gallery, 2-column tablet layout, 1-column mobile layout
- Filter photos by Skies, Places, and Quiet Things
- Click a photo to open the lightbox; use arrows or keyboard arrow keys to browse
- Responsive navigation and reduced-motion support
- Remote demo photos and Google Fonts require an internet connection

Note: Images are loaded from Unsplash URLs. Replace these with your own images if preferred.
